# Bunker

A structured thinking environment for high-stakes decisions. Lay out the decision, weight what matters, simulate what might happen, walk away with clarity.

## Concept

- Decision structuring
- What-if scenario analysis
- Risk assessment
- AI decision coaching
- Achievements to track progress

## Targets

- iOS

## Stack

- SwiftUI
- SwiftData
- XcodeGen (`project.yml`)

## Structure

Source under `Bunker/`, with `AppStore/` holding listing assets. Key types: `AIDecisionService`, `AIAnalysisService`, `AchievementService`, `AchievementsView`, `AnalyticsDashboardView`.

Version 1.0.

## Recovered work

Round 8 of what-if analysis, risk assessment, and AI decision coaching was recovered from a stash onto `rescue/stash-0` — it was never committed.

## Status

Apple-platform experiment built to explore what an AI coding agent could produce for a native app. Not actively maintained.

Xcode projects here were generated with XcodeGen (`project.yml`); open the `.xcodeproj` directly.
